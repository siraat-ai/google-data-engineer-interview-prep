## 3.3 Portfolio vs Resume

### 📌 Overview

When applying to Big Tech (e.g., Google, Amazon), both **portfolio** and **resume** play critical—but very different—roles.

> **Resume gets you the interview. Portfolio proves you deserve the job.**

---

### 🧠 Core Difference

| Aspect     | Resume                       | Portfolio               |
| ---------- | ---------------------------- | ----------------------- |
| Purpose    | Get shortlisted              | Demonstrate real skills |
| Format     | 1-page summary               | Detailed projects       |
| Depth      | High-level                   | Deep technical          |
| Focus      | Experience & impact          | Implementation & design |
| Evaluation | Recruiters + hiring managers | Engineers/interviewers  |

---

### 📄 Resume: Your Entry Ticket

#### What It Should Do

* Quickly communicate:

  * Skills
  * Impact
  * Relevance

#### Key Characteristics

* **Concise (1 page)**
* **Impact-driven**
* **Keyword-optimized**

#### ✅ Strong Resume Bullet

* “Built a scalable ETL pipeline processing 10M+ records/day using Spark, reducing query latency by 35%”

#### ❌ Weak Resume Bullet

* “Worked on data pipelines”

➡️ Focus on:

* **What you built**
* **How you built it**
* **What impact it had**

---

### 🧪 Portfolio: Your Proof of Work

#### What It Should Do

* Show you can:

  * Build real systems
  * Think like an engineer
  * Handle complexity

---

### 🧱 What Makes a Strong Portfolio

#### 1️⃣ End-to-End Projects

* Ingestion → Processing → Storage → Visualization

---

#### 2️⃣ Real Tools & Systems

* Cloud platforms (GCP/AWS)
* Data warehouses (BigQuery)
* Streaming/batch systems

---

#### 3️⃣ Clear Documentation

Each project should include:

* Problem statement
* Architecture diagram
* Tech stack
* Design decisions
* Trade-offs

---

#### 4️⃣ Clean Code (GitHub)

* Modular structure
* Readable code
* Proper README

---

### ⚙️ Example Portfolio Project

**Project:** Real-Time Analytics Pipeline

* Ingestion: Pub/Sub
* Processing: Dataflow
* Storage: BigQuery
* Visualization: Dashboard

**Highlights:**

* Handles streaming data
* Includes monitoring
* Optimized for cost

➡️ This shows **production-level thinking**

### 🧠 What Big Tech Actually Values

At Google:

* Resume:

  * Signals **potential**
* Portfolio:

  * Signals **capability**

➡️ Strong candidates have **both aligned**

---

### ⚖️ When You Have No Experience

| Situation          | What Matters More    |
| ------------------ | -------------------- |
| No work experience | Portfolio 🔥         |
| Some experience    | Both equally         |
| Strong experience  | Resume slightly more |

➡️ Portfolio can **replace experience**

---

### ⚠️ Common Mistakes

#### Resume Mistakes

* Too generic
* No measurable impact
* Too long

#### Portfolio Mistakes

* Toy projects
* No documentation
* No real-world relevance
* Only notebooks (no pipelines)

---

### 🎯 Interview Insight

Interviewers may:

* Ask you to:

  * Explain your projects
  * Justify design decisions
* Dive deep into:

  * Trade-offs
  * Scalability
  * Failures

➡️ If you can’t explain your project deeply, it loses value

---

### 🧠 Pro Tip

> Don’t just build projects—build projects you can **defend like a system design interview**

---

### ✅ Key Takeaways

* Resume = **marketing document**
* Portfolio = **technical proof**
* Both are essential, but serve different purposes
* Strong portfolio can:

  * Replace lack of experience
  * Deeply impress interviewers
* Align both to tell a **consistent, strong story**
